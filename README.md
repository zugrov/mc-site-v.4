# maxima consulting

Сайт maxima-consulting.ru. Ветка `redesign-awwwards` — редизайн «Ясность в деньгах».
В `main` не вливать без отдельной команды: merge публикует сайт.

## Лицензии

- **Manrope** — SIL Open Font License 1.1. Подмножество latin + cyrillic в `assets/fonts/manrope-var.woff2`.
- **JetBrains Mono** — SIL Open Font License 1.1. Подмножество latin + cyrillic в `assets/fonts/jetbrains-mono-var.woff2`.
- Текст лицензии: `assets/fonts/OFL.txt` и https://openfontlicense.org
- Иконки — инлайновые SVG в духе [Lucide](https://lucide.dev) (ISC). Платных шрифтов, стоков и библиотек нет.
- Google Fonts не используется.
